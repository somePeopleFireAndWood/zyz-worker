# zyz-worker

`zyz-worker` is an empty plugin scaffold for agent CLIs such as Codex and Claude Code.

The goal of this project is to grow into a productivity plugin that helps people develop, program, and complete other knowledge-work tasks more effectively.

## Status

This repository currently contains only the initial plugin structure. No functional skills, hooks, MCP servers, or apps have been implemented yet.

## Structure

```text
.
├── .codex-plugin/
│   └── plugin.json
├── assets/
├── skills/
│   └── zyz-worker/
│       └── SKILL.md
├── LICENSE
└── README.md
```

## Development

Future functionality should be added under `skills/`, `hooks/`, `scripts/`, MCP configuration, or app manifests as needed.
